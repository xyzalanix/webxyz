miscgen dsp

images displaced by the workflows that created them

This toolset reads metadata and extracts the workflow of an image created in ComfyUI. The nodes are plotted and used as a map for displacement.

It was initially built with the curiosity of exposing the image-making process, and using it as an identifier in the output itself. It's since evolved into a lightweight graphic kit where the displacement occurs between any 2 images.

It uses the jump-flood algorithm (JFA) to create displacement maps, inspired by a TouchDesigner patch that I've iterated and performed with over the years.

BASE is color. DISPLACE pushes it. Any image can play either part, or both at once. Press some numbers to change view mode.

In the default preset, the logo is carved into a base noise pattern. Any new image will automatically have a Depth twin that you can use for a more guided displacement.
